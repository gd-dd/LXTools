# LX 美术规范

## 图标归属

工具架使用作者提供的「纳西妲可爱剪刀手吐舌头」图，位于 assets/brand/，用于 EXE、窗口和侧栏。每个工具独立提供 manifest.icon；工具架不能覆盖工具图标。Max 工具集 1.0.1 使用「纳西妲抱 3ds Max」图。

## 白、嫩叶绿、发光金

界面中性色只定义三级：黑 #202020、白 #FFFFFF、灰 #777777。不额外引入米黄、棕灰、灰绿等多层底色。纯白在嫩叶绿映衬下已足够柔和，不叠加整片暖色滤镜。

- 白：页面、卡片、正文、输入框使用纯色背景，不做渐变。
- 嫩叶绿：清亮 #86B83D 作为导航、选中项、进度与滚动条；#507522 用于需要白字对比度的主按钮与绿色小字。
- 边缘、横幅和条状区域：嫩叶绿低透明度渐变，透出白底，变化微弱。使用 rgba 合成而不是新增一套灰度色阶。侧栏约 2–9%，横幅约 4–18%；正文避免渐变以保持清晰。
- 灰：辅助文字和细边框。边框按透明度淡化，不增加不同灰色常量。

## 白光香槟金与彩虹色散

选中、悬停、键盘焦点以白光为主，只带很淡的香槟金色温。禁止高饱和黄、橙金和古铜色。整圈底层 #FFFAF0，主光 #FFFFFF / #FFFDF5 / #FFF5DF；白底上用极淡香槟外轮廓保证可辨识，不依靠加深主光。

约 16 秒旋转一圈，局部点缀浅粉 #FFE0EB、淡紫 #E5DCFF、浅蓝 #DAF3FF、浅绿 #E2F8E7 的连续彩虹色散。保持高亮低饱和，彩色只占小段。不闪烁、不改变按钮尺寸、不遮挡文字。隐藏控件停止动画，禁用按钮不播放。

实现入口：src/theme.py 集中管理配色与透明渐变；src/gold_effect.py 管理动态金边。工具面板可沿用方向，自行组织布局；不强制重写插件原生界面。

色相修正：采用纳西妲风格的偏黄嫩叶绿，避免青绿、薄荷蓝绿。浅底仍为白色，不恢复米黄底；金色和局部彩虹色散保持独立。
