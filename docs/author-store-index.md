# 作者发布的商店索引

正式客户端手动刷新只请求固定地址 `https://raw.githubusercontent.com/gd-dd/LXTools/main/catalog/repo-store.json`，不再枚举作者仓库。启动优先使用安装包内置目录与本机缓存，不自动请求商店。开发客户端仍在明确刷新时额外扫描默认分支，提供同一卡片内的 0.0.0。

索引沿用 schemaVersion 2，每个条目保留 Release 身份、固定提交、工具完整 manifest、展示数据；增加 readmeData 与 panelBytes（原文件 base64），供客户端验证介绍与面板的声明摘要。iconData 原来已经是图片原文件 base64。旧缓存若缺少新校验字段会被忽略，已安装工具不受影响。索引最多 32 MiB / 1000 个历史版本；空索引、非法身份、重复版本、错误摘要、非法面板均拒绝。安装包需内置有效非空索引。

刷新成功后把响应 ETag 与同一份有效目录原子保存，下次使用 If-None-Match；304 保留目录。网络失败、限流、无效或空索引不覆盖已有数据，也不会自动退回昂贵全仓扫描。公开索引不发送登录令牌。该索引是作者的发现目录，不替代下载安全检查：主动安装重新取 Release，核对稳定状态、附件身份/大小/摘要、tag 对应 commit 和该提交的 manifest，再验证 ZIP 清单与每个文件摘要。

## 作者维护

在 LXTools 源码根运行：

```powershell
.venv/Scripts/python.exe -B scripts/build_store_index.py --output catalog/repo-store.json
```

这是显式作者维护入口，执行完整扫描、检测默认分支 LX 标记、保留所有合规稳定 Release，并检查完整视觉资源。可从进程 GH_TOKEN 读取凭据，不把令牌写入索引；公开仓库不要求登录。任何扫描警告或空结果使命令失败，原文件保留，避免限流造成工具消失。必须解决警告再生成。

工具作者先发布稳定 Release；维护者再生成、审核并提交索引到 LXTools/main。新工具、工具退役、历史新增都通过这次生成体现，不维护硬编码工具白名单。移除默认分支标记的仓库自然不进入下一份索引，旧安装继续可用。客户端正式打包同时嵌入这份索引；无需为每次单纯目录更新重新发布客户端。当前脚本不自动提交、推送或发版，不扩大 token 权限。

发布时检查四个当前有效工具、每个工具的新版本及历史版本；再用安装流程下载新包，独立记录冻结面板验证和宿主真实验证。未来若目录超过容量，再单独设计分页/详情分离，当前不引入新服务。
