## 醒来后建议人工验收

1. 双击主程序，看商店样式、字体、留白和卡片布局是否符合预期。
2. 在“我的工具”打开一个工具面板，再查看“版本与卸载”。
3. 建立中文夹子，在工具详情右上角收纳；重开客户端核对保存。
4. 安装好 Max 后，到“设置与更新”配置 3dsmax.exe，实测脚本功能。
5. 后续一起注册 GitHub 应用并完成账户授权接入。
